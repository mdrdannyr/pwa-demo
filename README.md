# PWA Demo

A tiny installable, offline-capable Progressive Web App: a to-do list saved in localStorage.

## Features

- Web app manifest (installable, standalone display)
- Service worker that pre-caches the app shell and works offline
- Online/offline indicator and a custom "Install app" button
- Light and dark themes

## Run locally

Service workers need http://localhost or HTTPS:

    python3 -m http.server 8000

Then open http://localhost:8000.

## Icons

The PNG icons are generated by `python3 tools/make_icons.py` (standard library only).

## Google sign-in

Uses Google Identity Services (see `auth.js`). The OAuth client ID lives in `config.js`; it is public, not a secret.
Authorized JavaScript origins must include https://mdrdannyr.github.io (and http://localhost:8000 for local testing).
This is a client-side demo with no backend: the name shown is for display only and is not secure authentication.

When you change any file, bump CACHE_NAME in `sw.js` so returning visitors get the update.
