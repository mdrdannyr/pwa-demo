    Share your file with others

    Your data file stays in your Google Drive. Invite people as editors and their changes will merge with yours.

    1. Enter a collaborator's Google email below and click Share.
    2. They receive a Google Drive notification with editor access to data.json in the PWA Demo folder.
    3. They open this app, go to Settings → Open a file shared with you, and select the file once. After that, edits sync automatically.

    You can manage or revoke access at any time in Google Drive.

    Open a file shared with you

    If someone has shared their PWA Demo data file with you, load it here to collaborate on the same document.

    1. Click Open shared file below.
    2. In the Google picker, choose Shared with me and select data.json.
    3. Google's narrow Drive permission requires this one-time step. Your local state will be merged into the shared file.

    The app checks for changes every 60 seconds while it is open.
